# Portfolio Quality Check

## Goal
Review the portfolio website and report actionable issues.

## Workflow
1. Inspect the HTML, CSS, and JavaScript files.
2. Check whether semantic HTML elements are used appropriately.
3. Review navigation links and interactive controls.
4. Check responsive layout rules for mobile, tablet, and desktop.
5. Review color contrast, keyboard accessibility, and alternative text.
6. Identify duplicated CSS or unnecessary JavaScript.
7. Use available browser tools when explicitly requested and available.
8. Do not modify files unless the user explicitly asks.
9. Do not deploy or push changes.

## Output
Provide:
- Issue
- File or component involved
- Why it matters
- Recommended fix
- Suggested validation steps

Prioritize issues by severity and explain any limitations in the inspection.
